# Courtly launch checklist

- [ ] Supabase project created and `supabase/schema.sql` executed
- [ ] Vercel project imported from GitHub
- [ ] Vercel build succeeds
- [ ] Custom domain and HTTPS configured (optional)
- [ ] Supabase Auth owner sign-in implemented
- [ ] Venue-owner access rules tested with two separate owners
- [ ] Public availability RPC and race-safe booking creation implemented
- [ ] Real payment provider connected and server webhook verifies payments
- [ ] Email notifications sent server-side
- [ ] Cancellation, refunds, time zones, and overlapping multi-hour bookings tested
- [ ] Privacy policy and terms added before public launch
